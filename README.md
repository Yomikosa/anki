# 公式暗記帳（DADS準拠・APIキー不要・スタサプ風穴埋め対応）

参考書やノートの公式を **APIキー不要・JSONコピペ方式** で登録し、**KaTeX数式の個別タップ穴埋め（スタサプ風）** で反復暗記できる静的Webアプリです。

UIは日本の **[デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/dads/)** のガイドラインおよびアクセシビリティ基準（コントラスト比 4.5:1 以上、本文最小 16px、44px 以上のタップ領域、`#FFCC00`＋黒枠の標準フォーカスリング）に準拠しつつ、透明感のあるフロストガラス質感と淡い半透明グラデーションを取り入れたモダンなデザインに仕上げています。

## 主な機能・UI設計

- **PC専用UI / スマホ専用UIの明確な分離**
  - **PC UI（900px以上、`css/layout-pc.css`）**: 左フロストガラス・サイドバーナビゲーション＋中央集中ワークスペース＋1行スリムツールバー。
  - **スマホ UI（899px以下、`css/layout-mobile.css`）**: スリムな 56px トップバー＋固定 DADS ボトムナビゲーション（ホーム／学習／追加／一覧）＋学習モード・絞り込み用ボトムシートにより、開いた瞬間に数式カードへ集中できる設計。

1. **ホーム**
   - 習得率・件数のひと目確認、優先学習（要復習／未習得）へのスマートCTA、科目別・状態別クイック起動デッキ、折りたたみ式の3ステップ使い方ガイド。
2. **学習する（穴埋め・選択クイズ・一問一答）**
   - **スタサプ風タップ穴埋めモード**: 数式や解説文の中の `{{...}}` を自動パースし、`[ ? ]` バッジとしてマスク。タップ／Enter・Spaceキーで**その箇所のKaTeX数式だけを個別に開閉**できます（`\frac{{-b \pm \sqrt{b^2 - 4ac}}}{{2a}}` のような分数・ルート内の入れ子ブレースにも対応）。
   - **4択穴埋めクイズモード**: 数式の穴埋め箇所を1つずつ青枠でハイライトし、APIキー不要のクライアントサイド自動生成エンジン（符号反転・係数違い・指数違い・類似変数などの「よくある間違い」を生成）による4つのKaTeX選択肢から選んで公式を完成させます。正誤の即時フィードバックと結果に応じたステータス更新提案付き。
   - **通常一問一答モード**: 3モード切替コントロールでワンタップ切替。問題文から公式を思い浮かべて「答えを表示する」で確認できます。
   - **一括操作**: 「すべて開く」「すべて隠す」セカンダリボタンで全穴埋めを一括開閉。
   - **習得ステータス管理**: 「習得済み」「復習が必要」「未習得」を `localStorage` に即時保存し、ステータス別・科目別フィルタリングおよびシャッフルに対応。
3. **公式を追加（JSON取込）**
   - **Gemini連携プロンプトコピー**: 参考書の写真と一緒に普段の Gemini（Web / アプリ）へ貼り付けるだけで、穴埋め対応済み＆バックスラッシュ適切エスケープ済みの JSON を生成するプロンプトをワンクリックコピー（プロンプト全文は折りたたみプレビューに収納）。
   - **バリデーション＆アラート**: コードフェンス（```` ```json ````）の自動除去、LaTeXバックスラッシュ未エスケープ（`\frac` → `\f` 等）の自動診断、KaTeX構文ドライランチェックを備え、DADSノティフィケーションバナーで分かりやすく結果を通知します。
4. **登録済み一覧・管理**
   - キーワード検索・ステータス絞り込み・KaTeXプレビュー一覧。
   - リアルタイムKaTeXプレビュー付きの編集／手動追加モーダル。
   - 折りたたみ式メニュー内に全データの JSON エクスポート（コピー／ファイル保存）、初期サンプル3件の復元・リセットを収納。

## 初期プリセット（初回起動時に自動登録）

1. 二次方程式の解の公式（数学）：`{{x}} = \frac{{-b \pm \sqrt{b^2 - 4ac}}}{{2a}}`
2. ニュートンの運動方程式（物理）：`{{m}}{{a}} = {{F}}`
3. 等加速度直線運動の変位の公式（物理）：`{{x}} = {{v_0 t}} + {{\frac{1}{2} a t^2}}`

## ローカル実行・テスト

ビルド不要の静的構成です。任意の静的サーバーでそのまま起動できます。

```bash
# ローカルプレビュー
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く

# パーサー・バリデーター単体テスト（Node.js 18+）
npm test
```

## 公開デプロイ手順

### GitHub Pages（同梱ワークフローで自動公開）

`.github/workflows/deploy-pages.yml` を同梱しています。

1. GitHub リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** で **GitHub Actions** を選択します。
3. `main` ブランチへプッシュすると自動でビルド＆公開され、`https://<ユーザー名>.github.io/<リポジトリ名>/` で利用できます。

### Vercel（ゼロ設定デプロイ）

1. [Vercel](https://vercel.com/new) で本リポジトリをインポートします。
2. Framework Preset は **Other**、Build Command は空欄、Output Directory は `.` のまま **Deploy** をクリックするだけで公開完了です。
